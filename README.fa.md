لینک آهنگ، آلبوم یا پلی‌لیست را از **اسپاتیفای / دیزر / اپل موزیک / یوتیوب / ساندکلاد** بچسبانید — یا همه‌ی کاتالوگ‌ها را یک‌جا جستجو کنید — و فایل صوتی تگ‌خورده با کیفیتی که خودتان انتخاب می‌کنید تحویل بگیرید (mp3 با ۱۲۸، ۱۹۲ یا ۳۲۰ کیلوبیت، یا همان استریم اصلی بدون دست‌کاری).

بدون حساب کاربری، بدون کلید API، بدون هزینه. خودتان اجرایش می‌کنید، پس فایل‌ها مال خودتان است و هیچ‌کس وسط نایستاده.

> رابط کاربری **فارسی و انگلیسی** است و از هدر صفحه — و روی موبایل از شیت تنظیمات — عوض می‌شود. پیش‌فرض فارسی است، چون مخاطب اصلی همین بوده ([چرا](docs/DESIGN.md#farsi-only))؛ اگر می‌خواهید انگلیسی باشد `UNSTREAM_DEFAULT_LOCALE=en` را ست کنید.

## دریافت برنامه دسکتاپ (پیشنهادی)

ساده‌ترین روش استفاده از آنستریم بدون نیاز به داکر. برنامه کاملاً محلی روی دستگاه شما اجرا می‌شود و فایل‌های موسیقی را مستقیماً در پوشه‌ی موزیک شما ذخیره می‌کند.

| سیستم‌عامل / پلتفرم | لینک دانلود | راهنما |
| --- | --- | --- |
| **مک (Apple Silicon)** | [دانلود فایل .dmg](https://github.com/amiralibg/unstream/releases/latest) | نسخه v1 بدون امضای اپل: کلیک راست روی برنامه و Open، یا دستور `xattr -d com.apple.quarantine /Applications/Unstream.app` |
| **مک (Intel)** | [دانلود فایل .dmg](https://github.com/amiralibg/unstream/releases/latest) | مشابه بالا |
| **ویندوز** | [دانلود فایل .exe](https://github.com/amiralibg/unstream/releases/latest) | در صورت اخطار SmartScreen: روی More info و سپس Run anyway بزنید |
| **لینوکس** | [دانلود .AppImage / .deb](https://github.com/amiralibg/unstream/releases/latest) | با `chmod +x` اجرا کنید یا با `dpkg -i` نصب نمایید |

## شروع سریع (داکر)

فقط به [داکر](https://docs.docker.com/get-started/get-docker/) نیاز دارید. نه پایتون، نه Node، نه ffmpeg روی سیستم‌تان.

<div dir="ltr">

```sh
git clone https://github.com/amiralibg/unstream.git
cd unstream
docker compose up -d
```

</div>

آدرس **<http://localhost:8080>** را باز کنید. چیزی جستجو کنید یا لینکی بچسبانید و دانلود را بزنید.

آهنگ‌های آماده در پوشه‌ی **`./downloads/<job-id>/`** می‌نشینند — فایل واقعی در پوشه‌ی واقعی، که می‌توانید هرجا که موسیقی‌تان را نگه می‌دارید منتقلشان کنید. هیچ‌چیز منقضی نمی‌شود و تا وقتی خودتان نخواهید پاک نمی‌شود.

کل نصب همین است. اگر خواستید چیزی را عوض کنید، `cp .env.example .env` و توضیحات داخلش را بخوانید؛ همه‌ی تنظیمات اختیاری‌اند.

### اجرا روی دستگاه‌های کوچک

رزبری‌پای، NAS، یا یک لپ‌تاپ قدیمی — همه بدون مشکل، و چیزی هم build نمی‌شود: `docker compose up` ایمیج‌های آماده‌ی `linux/amd64` و `linux/arm64` را از GHCR می‌کشد و فقط اگر نتوانست، از روی سورس می‌سازد.

روی **لینوکس**، مالکیت فایل‌هایی که نوشته می‌شود را به خودتان بدهید تا مال کاربر کانتینر نباشد:

<div dir="ltr">

```sh
echo "PUID=$(id -u)" >> .env
echo "PGID=$(id -g)" >> .env
docker compose up -d
```

</div>

روی مک و ویندوز لازم نیست — داکر دسکتاپ خودش این را مدیریت می‌کند.

## چطور کار می‌کند

سرویس‌های استریم با DRM محافظت می‌شوند، پس هیچ‌چیز مستقیماً از آن‌ها دانلود نمی‌شود. در عوض:

۱. **اطلاعات آهنگ** از منابع عمومی و بدون کلید می‌آید: صفحات embed اسپاتیفای، API عمومی دیزر، iTunes Search، وب‌ای‌پی‌آی ساندکلاد و خود yt-dlp. جستجو به‌صورت موازی روی چهار منبع پخش می‌شود و نتایج بر اساس نام و آرتیست یکی می‌شوند. **متن آهنگ** هم بدون کلید: اول LRCLIB — که تنها منبع با متن زمان‌بندی‌شده است و چند شکل مختلف از اسم آهنگ ازش پرسیده می‌شود، چون کاتالوگ‌ها یک آهنگ را جور به جور ثبت می‌کنند — بعد جینیوس و بعد lyrics.ovh. منبعی که جواب ندهد خودکار کنار گذاشته می‌شود و بعد از مدتی دوباره امتحان می‌شود، تا دانلود یک آلبوم پشت یک سرویس خراب معطل نماند.

۲. **yt-dlp** فایل صوتی را پیدا می‌کند: آهنگ‌هایی که از قبل به یوتیوب یا ساندکلاد اشاره دارند مستقیم دانلود می‌شوند و بقیه جستجو می‌شوند — نتیجه‌ای انتخاب می‌شود که مدت‌زمانش به کاتالوگ نزدیک‌تر باشد، که اجراهای زنده و میکس‌های یک‌ساعته را کنار می‌گذارد.

۳. **ffmpeg** با کیفیت انتخابی encode می‌کند. گزینه‌ی «اصلی» اصلاً encode نمی‌کند و استریم خود آپلود را نگه می‌دارد — بهترین کیفیت، چون encode دوباره‌ی یک منبع از قبل فشرده فقط کیفیت را کمتر می‌کند.

۴. **mutagen** تگ‌ها و کاور را داخل فایل می‌نویسد؛ اگر دکمه‌ی «متن آهنگ» بالای صفحه روشن باشد، متن آهنگ هم داخل فایل دانلودی ذخیره می‌شود.

## تنظیمات

همه اختیاری است. `cp .env.example .env` و هرچه لازم دارید را از کامنت خارج کنید؛ مرجع اصلی همان فایل است.

| متغیر                     | پیش‌فرض       | کار                                                                                                                |
| ------------------------- | ------------- | ------------------------------------------------------------------------------------------------------------------ |
| `UNSTREAM_PORT`           | `8080`        | پورت رابط وب                                                                                                       |
| `UNSTREAM_DEFAULT_LOCALE` | `fa`          | زبانی که بازدیدکننده‌ی تازه می‌بیند: `fa` یا `en`. هنگام بالا آمدن کانتینر خوانده می‌شود، پس بیلد دوباره لازم نیست |
| `DOWNLOADS_DIR`           | `./downloads` | جای فایل‌های آماده؛ می‌تواند هارد اکسترنال یا NAS باشد                                                             |
| `PUID` / `PGID`           | `1001`        | مالک آن فایل‌ها. روی لینوکس از `id -u` و `id -g`                                                                   |
| `DOWNLOADS_TTL_HOURS`     | `0` (هرگز)    | چند ساعت بعد فایل‌ها پاک شوند                                                                                      |
| `MAX_DOWNLOADS_GB`        | `0` (بی‌حد)   | سقف دیسک؛ بعد از آن قدیمی‌ترها حذف می‌شوند                                                                         |
| `DOWNLOAD_WORKERS`        | `3`           | تعداد دانلود هم‌زمان                                                                                               |
| `RATE_LIMITS_ENABLED`     | `false`       | محدودیت نرخ درخواست. **اگر غریبه‌ها دسترسی دارند روشنش کنید**                                                      |
| `ADMIN_TOKEN`             | خالی          | داشبورد `/admin` را فعال می‌کند؛ خالی یعنی اصلاً وجود ندارد                                                        |

### زبان

فارسی (راست‌به‌چپ) و انگلیسی (چپ‌به‌راست). هر کسی می‌تواند زبان را عوض کند — روی صفحه‌ی بزرگ از بالای صفحه، روی موبایل از شیت تنظیمات — و انتخابش در مرورگر خودش یادش می‌ماند؛ `UNSTREAM_DEFAULT_LOCALE` فقط تعیین می‌کند کسی که هنوز انتخابی نکرده چه می‌بیند.

```sh
echo "UNSTREAM_DEFAULT_LOCALE=en" >> .env
docker compose up -d
```

با ری‌استارت اعمال می‌شود، بدون بیلد دوباره — حتی روی ایمیج‌های آماده — چون کانتینر فرانت‌اند این تنظیم را هنگام بالا آمدن داخل یک `/config.js` کوچک می‌نویسد. عوض‌کردن زبان جهت متن، شکل اعداد، و عنوان و متادیتای اشتراک‌گذاری صفحه را هم همراه خودش عوض می‌کند.

**اضافه‌کردن زبان جدید** یک تنظیم نیست، دو فایل است: از `frontend/src/lib/locales/en.ts` کپی بگیرید، ترجمه کنید، و یک سطر به `LOCALES` در `frontend/src/lib/i18n.tsx` اضافه کنید. شکل این دیکشنری خودش یک تایپ است، پس عبارت جاافتاده باعث خطای بیلد می‌شود نه جای خالی در صفحه. اگر آن زبان اعداد را با ارقام خودش می‌نویسد، جای این تبدیل `app.num` در همان دیکشنری است — [قاعده‌ی ارقام](docs/DESIGN.md#digits) توضیح می‌دهد چرا این کار به فونت سپرده نشده.

## آیا می‌شود برای بقیه هاست کرد؟

برای دانلود آهنگ‌های یوتیوب روی یک VPS معمولی نه — و این دقیقاً دلیلی است که [برنامه دسکتاپ](#دریافت-برنامه-دسکتاپ-پیشنهادی) ساخته شده است.

یوتیوب آدرس دیتاسنتر را جور دیگری می‌بیند. از روی VPS همان اول `LOGIN_REQUIRED` می‌دهد — قبل از اینکه اصلاً نوبت به توکن یا حل چالش جاوااسکریپت برسد — پس دفاع‌هایی که داخل ایمیج هست فرصت کمک‌کردن پیدا نمی‌کنند. اما از روی برنامه دسکتاپ روی یک اتصال خانگی، هیچ‌کدام از این محدودیت‌ها وجود ندارد.

بقیه‌ی بخش‌ها — جستجو، دریافت متادیتا، اسکرپ اسپاتیفای و دیزر و اپل موزیک، متن آهنگ و دانلودهای ساندکلاد — روی VPS بدون مشکل کار می‌کنند. اگر می‌خواهید سرور عمومی هاست کنید، متغیر `UNSTREAM_YOUTUBE_DISABLED=true` را در `compose.dokploy.yml` بگذارید تا بقیه بخش‌ها به درستی کار کنند و برای یوتیوب کاربر را به برنامه دسکتاپ هدایت کند.

اگر به‌هرحال دیپلوی می‌کنید، از [`compose.dokploy.yml`](compose.dokploy.yml) استفاده کنید و حتماً **`RATE_LIMITS_ENABLED=true`** بگذارید. وقتی حساب کاربری وجود ندارد، محدودیت بر اساس IP تنها چیزی است که بین سرور شما و همه‌ی دنیا ایستاده.

## وقتی دانلود شکست می‌خورد

اول **`GET /api/admin/extraction`** را ببینید (به `ADMIN_TOKEN` نیاز دارد). می‌گوید واقعاً چه چیزی داخل کانتینر نشسته و فرق «اصلاً تنظیم نشده» با «تنظیم شده و باز هم بلاک است» را روشن می‌کند.

۱. **yt-dlp را به‌روز نگه دارید.** این دور زدن‌ها _داخل_ نسخه‌های yt-dlp منتشر می‌شوند، پس ایمیج قدیمی یعنی راه‌حل قدیمی. ایمیج‌های منتشرشده هفتگی دوباره ساخته می‌شوند.
۲. **حل‌کننده‌ی چالش جاوااسکریپت** — هم به runtime نیاز دارد (deno، داخل ایمیج هست) و هم به اسکریپتی که بار اول دانلود می‌شود.
۳. **سرویس توکن (pot-provider)** که به‌صورت پیش‌فرض روشن است.
۴. **کوکی**، فقط اگر موارد بالا کافی نبود — که روی اتصال خانگی تقریباً هیچ‌وقت لازم نمی‌شود. حتماً از یک **اکانت گوگل یک‌بارمصرف** استفاده کنید: تمام دانلودها به آن نسبت داده می‌شود و یوتیوب دقیقاً برای همین اکانت‌ها را می‌بندد.

## نکات حقوقی

این پروژه یک تمرین فنی روی API، پردازش مدیا و job پس‌زمینه است، و ابزاری برای رسیدن به موسیقی‌ای که از قبل حق استفاده‌اش را دارید.

**فقط چیزی را دانلود کنید که حقش را دارید.** رعایت قانون کپی‌رایت با خود شماست، و وقتی نسخه‌ی خودتان را اجرا می‌کنید، مسئولیتش هم با خودتان است.

آنستریم هیچ وابستگی یا ارتباطی با اسپاتیفای، دیزر، اپل، یوتیوب یا ساندکلاد ندارد. هیچ DRM ای دور زده نمی‌شود: چیزی از سرویس‌های استریم دانلود نمی‌شود و صدا از صفحات عمومی یوتیوب و ساندکلاد و از طریق yt-dlp می‌آید.
